BUILD (Java 25 requis)
  gradle build            (ou ./gradlew build si tu as le wrapper)
  -> build/libs/HeadDisguise-1.0.0.jar
Mets le .jar dans le dossier plugins/ du serveur Paper 26.2 et redemarre.

UTILISATION
  Craft : tete de joueur au centre + 8 eclats d'amethyste autour.
  Clic droit avec la tete : tu deviens ce joueur (nom + skin pour les autres).
  Sneak + clic droit ou /destransformer : tu redeviens toi.
